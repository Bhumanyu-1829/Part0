sequenceDiagram
    actor User
    participant Browser
    participant Server

    Note over User, Browser: 1. User enters text and clicks "Save"
    User->>Browser: Submits form (POST)

    Note right of Browser: 2. Browser sends form data to server
    Browser->>Server: POST https://studies.cs.helsinki.fi/exampleapp/new_note
    activate Server
    Note right of Server: 3. Server processes data, creates note object,<br/>adds timestamp, and stores in memory array.
    Server-->>Browser: 302 Redirect (Ask browser to GET /notes)
    deactivate Server

    Note right of Browser: 4. Browser executes redirect
    Browser->>Server: GET https://studies.cs.helsinki.fi/exampleapp/notes
    activate Server
    Server-->>Browser: HTML Document
    deactivate Server

    Note right of Browser: 5. Browser re-renders page structure,<br/>triggering GET requests for CSS/JS
    Browser->>Server: GET https://studies.cs.helsinki.fi/exampleapp/main.css
    activate Server
    Server-->>Browser: main.css
    deactivate Server

    Browser->>Server: GET https://studies.cs.helsinki.fi/exampleapp/main.js
    activate Server
    Server-->>Browser: main.js
    deactivate Server

    Note right of Browser: 6. Browser executes main.js, which<br/>fetches the updated notes data.
    Browser->>Server: GET https://studies.cs.helsinki.fi/exampleapp/data.json
    activate Server
    Server-->>Browser: Updated JSON Data (incl. new note)
    deactivate Server

    Note right of Browser: 7. Browser executes callback function,<br/>updating the DOM to display new notes list.
